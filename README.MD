# Empresa GLOWCLICK - Registro de Servicios.
## GLOWCLICK - Encapsulamiento y Validaciones en PHP
### Hoy apliqué los conceptos de Programación Orientada a Objetos (POO) en PHP para el módulo de registro de servicios de GLOWCLICK: Arquitectura Modular: Organización del código en carpetas (config/, models/, public/). Encapsulamiento: Protección de datos mediante atributos privados (private) y acceso controlado con Getters y Setters. Validación de Datos: Reglas de negocio en los Setters para evitar precios negativos, nombres vacíos o tiempos de duración inválidos. Manejo de Errores: Visualización de alertas cuando se intenta ingresar datos incorrectos, garantizando la integridad del sistema.
